         runs once, at boot). Main Menu -> Play a second time: the world
         is fresh, but no setup runs, and every game-wide manager

   Do:   A GameReset autoload (last in the list) records every game-wide

2. A full playthrough test  [protects playability]
   Every system has its own test; nothing plays the story from Day 1 to an
   ending. A headless test that walks the main path through the real
   interactions (enter the cabin, log in, patch the window, lock up, sleep,
   the Peeker, the nests, the upload, the car alarm and chase, Day 3, the
   van parts, the escape), checking the objective advances at every step,
   so a change that breaks the story's chain fails a test, not a player.

3. Test the exported build  [protects shipping]
   The export leaves out unused assets (tools/export_list.py). A file the
   game only loads by name (load("res://...")) could be missing in the
   build and only fail when it's needed. Do:
     - a test that finds every res:// path in the scripts and scenes and
       checks the export keeps each one;
     - build the export and launch it into the game scene for a while,
       checking its log for missing files and script errors.
