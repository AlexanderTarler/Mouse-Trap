LATER: THE WEB VERSION  (a project of its own, not for the MVP)
---------------------------------------------------------------
What was found trying it (2026-10-19):
  - Under 10 fps in Chrome on a GTX 1080 (the browser can only use the
	Compatibility renderer): needs an optimisation pass for the web (fewer
	and nearer forest batches, simpler shadows, cheaper fog and lamps, a
	lower resolution scale).
  - Firefox doesn't start it ("still waiting on run dependencies:
	loading-workers"): the threaded web template, which the TerraBrush
	terrain plugin's web library needs; a smaller thread pool might help.
  - Too bright: the web's own lighting values (compat_* in
	environment_controller.gd) haven't been tuned since the lighting
	changes.
  - The mouse doesn't turn the view: browsers lock the mouse only during a
	click, and Play now waits for the sunset first, so the lock comes too
	late. Request the lock in the click itself.
  - On itch.io it needs "SharedArrayBuffer support" ticked.
	Local test: python tools/serve_web.py, http://localhost:8060 (Chrome).
